# Задание 1. Инкапсуляция: private, геттеры и сеттеры, выбрасывание исключений через throw, класс RuntimeException и его наследники.

## Задача 1.5. - Перезарядка Пистолета.
**Условие:** Изменить сущность Пистолет. Он имеет максимальное количество патронов (устанавливается при создании и не меняется). Может быть перезаряжен (если число отрицательное — ошибка, если больше максимума — лишние возвращаются). Может быть разряжен. Можно узнать текущее количество патронов и статус (заряжен/разряжен). Продемонстрировать на примере: создать пистолет вместимостью 7, зарядить 3, выстрелить 5 раз, зарядить 8, выстрелить 2 раза, разрядить, сделать контрольный выстрел.

**Алгоритм решения:**
Создан класс `Gun`. Для хранения патронов используются поля `protected int maxCartridges` и `protected int cartridges`. В методе `setCartridges(int x)` реализована проверка `if (x < 0)`, которая выбрасывает исключение `IllegalArgumentException` (наследник `RuntimeException`). В главном меню (`menu2`) это исключение перехватывается через `try-catch`. Если пользователь вводит число больше максимального, программа возвращает разницу (`catridges - gun.getMaxCartridges()`). Метод `toString` имитирует выстрел: если патронов нет — выводит "\nКлац!", иначе уменьшает счетчик на 1 и выводит "\nБах!".

# Задание 2. Разработка структур данных.

## Задача 2.1 - Неизменяемый массив.
**Условие:** Создать обертку над массивом целых чисел. Инициализация: массивом, перечнем чисел, копией другого списка. Действия: получение/замена по индексу (с проверкой ошибки), приведение к строке, проверка на пустоту, размер, получение стандартного массива.

**Алгоритм решения:**
Создан класс `IntList`. Внутри хранится `private final int[] values`. Конструкторы используют `System.arraycopy` для копирования данных, что гарантирует независимость списка от внешних массивов. Для проверки выхода за границы диапазона написан вспомогательный метод `checkIndex(int pos)`, который выбрасывает `IllegalArgumentException`. Метод `toString` собирает строку через `StringBuilder` в формате `[1, 2, 3]`.

# Задание 3. Наследование: extends, super, final, переопределение.

## Задача 3.4 - Автомат.
**Условие:** Создать подвид Пистолета. Имеет неизменяемую скорострельность. При вызове «Стрелять» делает количество выстрелов, равное скорострельности. Умеет стрелять N секунд (N * скорострельность). Инициализация: по умолчанию (30 патронов, 30 скорострельность), только с обоймой (скорострельность = обойма/2) или с обоими параметрами.

**Алгоритм решения:**
Создан класс `MachineGun extends Gun`. Добавлено поле `RateOfFire`. В конструкторах используется вызов родительского конструктора `super(x, 0)`. Метод `shotPerNSecond(int N)` вычисляет общее количество выстрелов и в цикле вызывает унаследованный метод `show()`, имитируя стрельбу очередью.

# Задание 5. Полиморфизм: виртуальный вызов метода, interface, implements.

**Алгоритм решения:**
Создан класс `Shooter`. Он хранит строку `name` и ссылку на базовый тип `Weapon` (благодаря полиморфизму, сюда можно положить как `Gun4`, так и `MachineGun4`). В методе `shoot()` проверяется `if (this.weapon != null)`, и если оружие есть, вызывается `this.weapon.shoot()` (срабатывает динамическое связывание и вызывается метод конкретного оружия). В меню (`menu6`) стрелки хранятся в динамическом списке `ArrayList<Shooter>`, что позволяет создавать их в любой момент.
